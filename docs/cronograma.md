## 3. Marcos do projeto

Os principais milestones definidos para o projeto são:

### Milestone 1 — Definição do projeto

Organização, área de atuação, problema e objetivos definidos.

### Milestone 2 — Dataset definido

Base de dados selecionada e organizada no repositório.

### Milestone 3 — Metadados documentados

Variáveis e características das bases documentadas.

### Milestone 4 — Base preparada

Dados tratados e preparados para as análises.

### Milestone 5 — Indicadores definidos

Indicadores relacionados ao desempenho logístico estabelecidos.

### Milestone 6 — Análise concluída

Análises exploratórias e visualizações desenvolvidas.

### Milestone 7 — Documentação concluída

Documento acadêmico e documentação do GitHub revisados.

### Milestone 8 — Entrega final

Projeto finalizado e entregue conforme os prazos do componente
curricular.
