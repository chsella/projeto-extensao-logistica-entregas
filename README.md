# Projeto de Extensão – Análise de Logística e Entregas

## Integrantes

- Ingryd Cristine Hidalgo Sella

## Objetivo

Este projeto tem como objetivo analisar dados relacionados a operações
logísticas e entregas, buscando identificar padrões de desempenho e
fatores associados aos atrasos.

## Problema

Como a análise de dados pode auxiliar na identificação de fatores
associados aos atrasos nas entregas e contribuir para o acompanhamento
do desempenho logístico?

## Estrutura do projeto

- `data/` – bases de dados utilizadas no projeto
- `notebooks/` – notebooks utilizados na análise
- `src/` – códigos auxiliares
- `resultados/` – gráficos e tabelas produzidos
- `docs/` – documentação e metadados

## Tecnologias

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Etapas

1. Coleta dos dados
2. Tratamento dos dados
3. Análise exploratória
4. Análise dos indicadores logísticos
5. Visualização dos resultados
6. Documentação dos resultados

## Repositório

Este repositório contém os arquivos, códigos, dados e documentação
